# 迷宫来源

- 生成器：`travisjayday/mazegen`
- 固定版本：`102d58c27efebfd5ef00141e922bd4066a7024cf`
- 地址：<https://github.com/travisjayday/mazegen>
- 生成命令：`mazegen -d 13 9 -o`

`maze_layout.txt` 是该生成器输出的 13×9 二维迷宫，`█` 表示墙体，空格表示通道。
从生成器的多个输出中，按“入口内侧朝南、左侧优先”策略筛选出路径较短且以
左转、直行为主的布局，再固定保存以避免随机变化。

导入时每格边长设为 0.6 m，内部通道净宽为 0.6 m。原图单格进出口在生成
Gazebo world 时扩宽为 3 格，即 1.8 m；机器人横向外廓约 0.32 m。
生成 world 时将入口扩为第 5～7 列、出口扩为第 10～12 列，单侧净宽 1.8 m。
机器人从入口内侧第 6 列开始，面向迷宫内部执行左侧优先搜索。
